1. Accès au dépôt GitHub

Dépôt : marocnetmail/125 — branche main. Fichiers gérés : json/reelsData.json (vidéos), json/themes.json (thèmes), json/url_content.json (transcriptions).

Le jeton GitHub est saisi via la fenêtre de connexion qui s'affiche au démarrage. Il reste uniquement en mémoire pendant la session et n'est jamais enregistré (ni sur disque, ni dans le navigateur, ni sur GitHub).

Seuls titre, description, thème français et thème arabe sont modifiables. La transcription (champ contenu dans url_content.json) se modifie via le bouton Modifier le contenu de chaque ligne. Cliquez sur Date de publication ou Vues pour trier.
